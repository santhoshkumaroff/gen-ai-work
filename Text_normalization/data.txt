open     file and return a stream.  raise oserror upon failure.
file is either a text or  byte string giving the name 
(and the path if the file isn't in the current working directory) 
of the file to be opened    or an integer 
file descriptor of the     file to be wrapped. 
(if a file descriptor is given, it is closed when the returned i/o object
 is closed, unless closefd is set to false.)
